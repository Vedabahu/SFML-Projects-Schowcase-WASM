Project Overview

Vedabahu’s Random SFML Graphics - 1 is an experimental rendering showcase built using SFML and compiled to WebAssembly using Emscripten.

The project focuses on rendering colorful rotating pentagons directly in the browser through a native C++ rendering pipeline.

Technical Stack

  • SFML
  • WebAssembly (WASM)
  • Emscripten
  • CMake

Purpose

This project was created to explore advanced C++ workflows, browser-based native rendering, and WebAssembly deployment using SFML.
